# # BolKhata — Voice-First Kirana Ledger & Inventory Copilot

**Created by Haridas Ghosh** | New Delhi, India

BolKhata helps busy Indian *kirana* shopkeepers record customer *udhaar* (credit), log payments received, and track inventory hands-free using natural Hindi and Hinglish voice commands.
